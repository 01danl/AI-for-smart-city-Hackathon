# Превью новой карты

Экспериментальная ветка `feat/map-preview`. Изменения касаются только интерфейса.

## Что изменилось

- Более подробная светлая подложка CARTO Voyager и отдельная тёмная тема карты.
- Лазурная линия с контрастной обводкой и указателями направления.
- Маркеры с номерами карточек; дополнительные остановки маршрута показаны небольшими точками.
- Названия мест и подсказки со статусами работы. В начальном масштабе пересекающиеся подписи скрываются.
- Отдельная точка старта и зона округления около 100 м.
- Сводка расстояния, времени пешком и количества остановок, последовательность посещения под картой.
- Кнопка «Весь маршрут» возвращает исходный масштаб. Темы и подписи меняются без повторного запроса к модели.

## Проверка

Из корня рабочей копии этой ветки:

```bash
uv run --locked streamlit run frontend/app.py --server.address 127.0.0.1 --server.port 8502
```

Открыть `http://127.0.0.1:8502` и выбрать сценарий. Для просмотра карты ключ LLM не нужен.
В меню «Вид карты» доступны светлая/тёмная тема и отображение названий.

Линия показывает **порядок переходов между настоящими POI**, а не пешеходный путь по улицам.
Ссылка Google Maps открывает навигацию. Геометрия, расстояния и время исходного ответа не меняются;
внешний API маршрутизации не добавлен. Стандартная версия приложения остаётся отдельно от этого превью.
