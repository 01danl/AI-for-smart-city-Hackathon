## Как получены поля

- Название и адрес извлечены из HTML карточки. Координаты взяты из `ymaps.Placemark` этой же страницы; адрес не геокодировался, координаты не придумывались.
- Расписания вручную сопоставлены стандартному формату `opening_hours`, затем проверены на наличие исходной формулировки в загруженной странице. Учтены выходные и обеденные перерывы.
- В музее пожарных посещение по предварительному звонку: условие сохранено дословно в `description`, расписание оставлено `null`, статус — `unknown`.
- У Дворца «Жастар» указаны часы без дней недели: расписание оставлено `null`. Телефоны приёмной/СМИ не выдаются за телефон для посетителей.
- Категории — внутренняя классификация по типу учреждения. Теги удобств, рейтинги, отсутствующие сайты и описания не добавлялись.
- `data/poi_sources.json` хранит ссылки, дату загрузки, адреса, исходные формулировки и SHA-256 полученных страниц. `data/official_poi.json` — отдельное официальное дополнение; `data/poi.json` — общий набор.
- 966 исходных OSM-записей не изменены и не объявляются официально проверенными. Обновлённый сборщик OSM сохраняет отдельное официальное дополнение.

## Отложено без добавления

- Книжный музей, музей сингулярности alem.ai, театр имени Мамбетова, театр «Современник»: из полученных страниц не удалось извлечь полный обязательный набор название/адрес/однозначная точка карты. Координаты не заменялись предположением.
- Инклюзивный театр «Қанаттылар» и Музыкальный театр юного зрителя: точки находятся соответственно примерно в 5 и 12 метрах от уже имеющихся театров с другими названиями. Требуется разобраться в совместном размещении или переименовании; новые дубли не созданы.

## Воспроизведение

```bash
python scripts/collect_official_poi.py --download
python scripts/collect_official_poi.py
# После проверки соседних объектов и изменений источника:
python scripts/collect_official_poi.py --apply
python scripts/describe_data.py
```

Список разрешённых карточек и подтверждения расписаний: `data/official_poi_manifest.json`.
Исходные страницы сохраняются локально в игнорируемой папке `data/raw/visit_astana/`.
При изменении текста расписания, отсутствии или неоднозначности координат импорт останавливается до записи общей базы.

## Ограничения

Проверено соответствие данным портала, а не фактическая работа заведений на месте. Маркер на карте может обозначать здание, а не вход. Перед посещением нужно уточнять режим и условия. Праздничные исключения на этих страницах не указаны.

После изменения данных запущенные процессы нужно перезапустить, чтобы очистить кэш. При использовании Chroma необходимо пересобрать индекс; BM25 строится из JSON при следующем запуске.

## Проверка

Тесты импорта проверяют отказ без координат/при нескольких точках, изменение подтверждения расписания, обеденный перерыв и посещение по записи.
Существующий сценарий `test_s7_english_query` не проходит и на прежних 966 записях: книжный магазин ранжируется выше библиотеки. Это отдельная проблема поиска, данные ради теста не изменялись.
